#+TITLE: gcal.el
#+AUTHOR: AKIYAMA Kouhei

Google Calendar API client for Emacs.

Interact with Google Calendar directly from Emacs. List calendars, query events, create new entries, and synchronize your org-mode schedule with Google Calendar.

* Features

- Full Google Calendar API access via OAuth 2.0
- List, create, update, and delete calendar events
- Bidirectional sync between org-mode files and Google Calendar
- Time zone support
- Delta synchronization for efficient updates

* Requirements

- Emacs 26.1 or later
- Google Cloud Platform project with Calendar API enabled

* Installation

Clone this repository and add it to your load path:

#+BEGIN_SRC elisp
(add-to-list 'load-path "/path/to/gcal.el")
(require 'gcal)
#+END_SRC

* Configuration

** Google API Credentials

1. Go to the [[https://console.developers.google.com/][Google Cloud Console]]
2. Create a new project or select an existing one
3. Enable the Google Calendar API
4. Create OAuth 2.0 credentials (Desktop application)
5. Configure the client ID and secret:

#+BEGIN_SRC elisp
(setq gcal-client-id "YOUR_CLIENT_ID.apps.googleusercontent.com")
(setq gcal-client-secret "YOUR_CLIENT_SECRET")
#+END_SRC

** Time Zone

Set your default time zone (IANA format):

#+BEGIN_SRC elisp
(setq gcal-default-time-zone "America/New_York")
#+END_SRC

* Usage

** Basic Calendar Operations

#+BEGIN_SRC elisp
(require 'gcal)

;; List all your calendars
(gcal-calendar-list-list)

;; List events from a specific calendar
(gcal-events-list
 "your-email@gmail.com"
 `((timeMin . ,(gcal-datetime 2024 1 1))
   (timeMax . ,(gcal-datetime 2024 2 1))))

;; Create a new event
(gcal-events-insert
 "your-email@gmail.com"
 `((start . ,(gcal-gtime 2024 1 15))
   (end . ,(gcal-gtime 2024 1 16))
   (summary . "Team Meeting")))

;; Delete an event
(gcal-events-delete "your-email@gmail.com" "event-id")
#+END_SRC

** Org-mode Integration

Synchronize your org files with Google Calendar:

#+BEGIN_SRC elisp
(require 'gcal-org)

;; Push an org file to Google Calendar
(gcal-org-push-file "your-email@gmail.com" "~/schedule.org")

;; With custom cache file
(gcal-org-push-file "your-email@gmail.com" "~/schedule.org" "~/schedule.gcal-cache")
#+END_SRC

** Parsing and Uploading Events

#+BEGIN_SRC elisp
;; Parse org buffer for events
(gcal-org-parse-buffer)

;; Parse a specific org file
(gcal-org-parse-file "~/schedule.org")

;; Upload events to Google Calendar
(gcal-org-push-oevents
 "your-email@gmail.com"
 (gcal-org-parse-file "~/schedule.org")
 nil)

;; Delta upload (only changes)
(gcal-org-push-oevents
 "your-email@gmail.com"
 (gcal-org-parse-file "~/schedule.org")
 (gcal-org-parse-file "~/schedule.org.old"))

;; Delete events from Google Calendar
(gcal-org-push-oevents
 "your-email@gmail.com"
 nil
 (gcal-org-parse-file "~/schedule.org"))
#+END_SRC

** Downloading Events

#+BEGIN_SRC elisp
;; Download events from Google Calendar
(gcal-org-pull-oevents
 "your-email@gmail.com"
 `((timeMin . ,(gcal-time-format (current-time) nil))))
#+END_SRC

* API Reference

| Function                  | Description                    |
|---------------------------+--------------------------------|
| =gcal-calendar-list-list= | List all calendars             |
| =gcal-events-list=        | List events from a calendar    |
| =gcal-events-get=         | Get a specific event           |
| =gcal-events-insert=      | Create a new event             |
| =gcal-events-update=      | Update an existing event       |
| =gcal-events-patch=       | Partially update an event      |
| =gcal-events-delete=      | Delete an event                |
| =gcal-events-quick-add=   | Quick add event from text      |
| =gcal-org-push-file=      | Sync org file to calendar      |
| =gcal-org-parse-buffer=   | Parse current buffer for events|
| =gcal-org-parse-file=     | Parse org file for events      |
| =gcal-org-push-oevents=   | Upload parsed events           |
| =gcal-org-pull-oevents=   | Download events from calendar  |
